# Воскресная компьютерная школа

Статический сайт на Astro. Содержимое страниц редактируется в `src/pages/*.md`. Общие части сайта находятся в `src/components/` и `src/layouts/`, пункты меню — в `src/data/navigation.ts`.

## Локальный запуск

```sh
npm install
npm run dev
```

Проверка и сборка:

```sh
npm run check
npm run build
```

Готовые файлы появляются в `dist/`. Каждая внутренняя страница собирается как каталог с `index.html` внутри. Чтобы публичные адреса оставались строго вида `/courses` (без `.html` и завершающего `/`), при размещении нужен внутренний rewrite `/courses` → `/courses/index.html` и аналогично для остальных страниц, без внешнего 301/302-редиректа. Это проверяется после выбора и настройки статического веб-сервера.

## Содержимое

Изображения кладите в `public/images/` и указывайте в Markdown по исходному URL, например `![Описание](/images/photo.jpg)`. Документы кладите в `public/downloads/` и добавляйте ссылки вида `[Скачать программу](/downloads/program.pdf)`.

Файлы страниц сохранены в UTF-8. Старые материалы нужно переносить вручную после проверки их содержимого.
