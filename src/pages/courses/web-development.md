# Веб-разработчик

### Общая характеристика курса

На курсе *Веб-разработчик* школьники изучают HTML, CSS и основы JavaScript, создают адаптивные веб-страницы и небольшие интерактивные приложения. Они учатся работать с макетами в Figma, переносить дизайн в HTML и CSS, добавлять реакцию на действия пользователя, проверять страницы с помощью инструментов браузера и публиковать готовые проекты в интернете.

Искусственный интеллект используется как вспомогательный инструмент для поиска вариантов, объяснения кода, диагностики ошибок и проверки результата. Ученики учатся оценивать его ответы и использовать только те решения, которые понимают и могут объяснить.

В течение курса каждый школьник создаёт несколько законченных проектов и формирует портфолио работ. Курс рассчитан на учеников 8–10 классов. Предварительное знание программирования не требуется.

Знания, полученные на курсе [Пользователь прикладных программ](/courses/applications), обязательны.

**Основная цель курса** − сформировать практические навыки разработки, проверки и публикации современных веб-сайтов.

### Краткая программа курса

**HTML**  
Структура веб-страницы, текст, изображения, ссылки, семантические элементы и формы.

**CSS и адаптивная вёрстка**  
Оформление страниц, блочная модель, Flexbox, Grid и медиазапросы.

**JavaScript**  
Переменные, условия, функции, массивы, события и работа с элементами страницы.

**Figma**  
Чтение макетов, определение размеров, цветов, шрифтов и расстояний, экспорт изображений.

**Инструменты веб-разработчика**  
Редактор кода, DevTools, консоль браузера, поиск ошибок и публикация сайтов.

**Работа с искусственным интеллектом**  
Постановка задач, объяснение кода, поиск причин ошибок и проверка предложенных решений.

**Системы управления содержимым**  
WordPress, установка, настройка, администрирование.

**SEO-оптимизация**  
Продвижение сайта, счетчики, использование Яндекс-веб-мастера.
